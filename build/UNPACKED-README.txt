Fluent Reader Alpine — Windows x64 unpacked edition

Extract this archive and run fluent-reader-alpine.exe.
Microsoft Edge WebView2 Runtime must be installed on your system.
Application data stays in your Windows user application-data directory.

A lightweight edition of Fluent Reader by Haoyuan Liu and its contributors.
